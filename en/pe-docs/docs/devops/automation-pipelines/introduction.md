# What are Automation Pipelines

!!! info "Note"
    Automation pipeline capabilities are only available for private data plane organizations.

{{ product_name }} provides the capability to define and run any automated workflow with multiple steps within your IDP infrastructure. You can write your automation pipeline using the [{{ product_name }} pipeline syntax](https://github.com/wso2/choreo-pipeline-specification/tree/main/docs/specification) which is a simplified version of [Argo workflows syntax](https://argoproj.github.io/workflows/) syntax.
